MEDCOLLEGE CLINIC ONLINE — ОКУУ ҮЧҮН

1. Python 3.10+ орнотуңуз (python.org).
2. Папкада терминалды ачыңыз.
3. python server.py  (Windows: py server.py)
4. http://localhost:8000 ачыңыз.
5. Биринчи иштеткенде терминалда teacher логининин кокустук сырсөзү чыгат.
6. Окутуучу студенттердин логиндерин түзүп, тапшырма берет жана баалайт.

Бир эле Wi-Fi тармагында: сервер иштеген компьютердин жергиликтүү IP дареги менен
http://IP-ДАРЕК:8000 аркылуу кирүүгө болот (firewall уруксат берсе).

ИНТЕРНЕТ АРКЫЛУУ ЖАЙГАШТЫРУУ:
Бул долбоор даяр окуу прототиби. Аны жалпыга ачык интернетке жайгаштыруудан
МУРДА HTTPS, резервдик көчүрмө, сырсөздү алмаштыруу/калыбына келтирүү,
rate limiting, CSRF коргоосу, ролдорду аудиттөө жана коопсуз хостинг талап кылынат.
Жөн гана Netlify'га жүктөө жетишсиз: Python сервер жана SQLite керек.

Чыныгы бейтаптын маалыматтарын киргизбеңиз. Расмий документ эмес.
clinic.sqlite3 — жалпы база. Анын резервдик көчүрмөсүн алып туруңуз.
